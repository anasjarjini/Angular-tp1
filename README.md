# Angular TP1 - Formulaires

Ce projet est une application Angular illustrant la gestion des formulaires (Template-driven Forms et Reactive Forms).

- **Auteur** : Anas El Jarjini
- **Dépôt GitHub** : [https://github.com/anasjarjini/Angular-tp1](https://github.com/anasjarjini/Angular-tp1)

---

## Fonctionnalités

- Formulaires pilotés par le template (**Template-driven Forms**)
- Formulaires réactifs (**Reactive Forms**) avec validation
- Interface utilisateur avec **Angular Material**

---

## Démarrage rapide

### 1. Installation des dépendances
```bash
npm install
```

### 2. Lancer le serveur de développement
```bash
npm start
# ou
ng serve
```
Ouvrez votre navigateur sur `http://localhost:4200/`. L'application se recharge automatiquement lors des modifications.

### 3. Build de production
```bash
npm run build
```
Les fichiers compilés se trouveront dans le répertoire `dist/`.

### 4. Tests unitaires
```bash
npm test
```
